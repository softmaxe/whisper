# Changelog

## [1.0.0] - 2026-09-16

Initial whisper release, based on OpenWhispr 1.10.2 at commit `834a0771`.

- Self-hosted ASR and cleanup with custom endpoints, models, and the original Prompt Studio.
- Dictionary, Snippets, local History, and dictation Insights.
- Local audio/video file uploads and batch transcription, saved to History.
- macOS dictation shortcuts, automatic paste, and a persistent menu bar icon toggle.
- Original UI components and colors, JetBrains Mono, and system PingFang for Chinese.
- Apple Silicon ZIP releases with checksums and automatic Homebrew tap updates.

Upstream changes are documented in the [OpenWhispr changelog](https://github.com/OpenWhispr/openwhispr/blob/834a0771/CHANGELOG.md).
